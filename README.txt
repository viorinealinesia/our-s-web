PENTING UNTUK GITHUB PAGES:
1. Upload SEMUA file dan folder assets ke repository.
2. Jangan memisahkan file dari folder assets.
3. Pastikan nama file dan folder sama persis (GitHub case-sensitive).
4. Buka index.html dari root repository.
5. Jika memakai GitHub Pages, pilih Settings > Pages > Deploy from branch > main > /(root).

Path asset sudah dibuat relatif (./assets/...), sehingga background, foto, dan favicon tetap terbaca saat website dijalankan dari GitHub Pages.

Catatan:
- Background dipertahankan sebagai file asli di assets/background.jpg.
- Favicon/icon kucing-pita yang sekarang ikut di-upload dan dipanggil dari folder assets.
- Foto memories tetap menggunakan file asli yang ada di ZIP.
